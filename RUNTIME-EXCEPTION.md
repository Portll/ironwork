## 0. Definitions

**"Input Program"** means source code that ironwork compiles, checks or interprets, in COBOL or any
other language, together with the copybooks, data and job control it reads.

**"Runtime Library"** means the parts of ironwork that are copied into, linked with or loaded by a
Compiled Program so that it can run, including code ironwork generates from its own templates.

**"Compiled Program"** means anything ironwork produces from an Input Program, such as object code,
an executable, intermediate code or a listing, together with the Runtime Library as incorporated
in it.

## 1. Compiled Programs

You may convey a Compiled Program, and any work that combines a Compiled Program with other works,
under terms of your choice, even though it incorporates the Runtime Library. The AGPLv3 does not
require you to provide the source of an Input Program or of a Compiled Program, or to license
either under the AGPLv3, because ironwork compiled it.

## 2. Input Programs and what they do

The AGPLv3 does not apply to an Input Program because ironwork compiles, checks or interprets it,
nor to what an Input Program does when it runs, whether compiled or interpreted, including when
users interact with it over a network. Section 13 of the AGPLv3 applies to ironwork itself and to
modified versions of ironwork, not to an Input Program.

## 3. What this exception does not do

It does not permit you to convey ironwork, or a modified version of ironwork, other than under the
AGPLv3 with this exception. It does not permit you to use the Runtime Library other than as part of
a Compiled Program. If you modify ironwork, you may extend this exception to your version, but you
are not obliged to; if you do not, remove it from your version.

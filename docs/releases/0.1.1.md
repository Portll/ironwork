ironwork for COBOL 0.1.1. Builds for Linux (static), macOS and Windows, and the npm package @portll/ironwork. The Python package is on PyPI as ironwork, and the crates are on crates.io.

## Summary

Installs from PyPI and npm, with builds for each platform.

- The machine and compiler models, and the oracle.
- The interpreter: COPY, sequential, indexed and relative files, and subprograms.
- EXEC SQL and EXEC CICS checked when compiled; CICS tasks, BMS maps and the TN3270 server.
